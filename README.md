OK 影视 Pro，基于开源项目 FongMi TV（原 CatVodTV）深度定制，是面向安卓电视、盒子与安卓手机的影视播放器。采用 Android TV Leanback 原生界面，支持点播、电视直播，可自定义导入播放源，自由度极高。

- 开源基底：依托 FongMiTV 开源仓库，持续更新维护，可自行编译构建

## 二、音乐软件推荐

### 1.LX music
项目仓库：https://github.com/lyswhut/lx-music-desktop
下载官网：https://www.lxmusic.cn/

LX Music（洛雪音乐）是一款开源免费的跨平台音乐播放器。软件本体仅为播放器外壳，**不内置任何音乐资源**，可导入第三方音源来聚合多平台音乐，支持本地音乐播放。

✅ **优点**
- 完全开源免费，无广告，界面干净简洁
- 跨平台支持：Windows、macOS、Linux、安卓（暂不支持iOS）
- 支持无损音乐播放、桌面歌词、全局快捷键、歌单管理
- 支持本地音乐文件播放，可自定义主题外观
- 无需强制登录账号即可使用基础播放功能

❌ **缺点**
- 软件本身不带音源，需要用户自行寻找、导入音源脚本才能使用在线播放，上手门槛更高
- 音源由第三方维护，音源容易失效，稳定性不受项目官方保障
- 缺少原生智能歌曲推荐，没有官方曲库
- 部分音源会出现歌曲音质不稳定、部分曲目无法播放的情况

> 本音乐软件仅仅只是一个壳子，如要正常使用还需接入音源，这里提供音源项目地址
>
> [GitHub - guoyue2010/lxmusic-: lxmusic(洛雪音乐)全网最新最全音源 · GitHub](https://github.com/guoyue2010/lxmusic-)

###  2.spotify

## 三、笔记软件

### 1.obsidian

下载地址：[Obsidian - 磨砺你的思维](https://obsidian.md/zh/)

Obsidian 是一款强大的本地知识库笔记软件，基于本地 Markdown 文件存储，主打双向链接与知识图谱，适合搭建个人第二大脑。

✅ **优点**
- 所有笔记以 Markdown 文件保存在本地，完全由你掌控，不存在平台锁库，可直接用其他编辑器打开
- 核心特色**双向链接**：能看到当前笔记被哪些其他笔记引用，方便串联知识
- 知识图谱可视化，直观查看笔记之间的关联关系
- 丰富的社区插件生态，可扩展模板、日历、思维导图、图表等大量功能
- 支持离线使用，无需联网，隐私性强；支持移动端、Windows、macOS、Linux多端
- 自定义程度高，可更换主题、调整样式

❌ **缺点**
- 基础同步功能需要付费订阅 Obsidian Sync，免费同步需要自己搭建方案（如网盘、WebDAV）
- 上手门槛偏高，搭建个人知识库需要花时间熟悉双向链接、标签等概念
- 原生没有内置云同步，跨设备同步需要自行配置
- 软件本身不自带图片托管，插入图片同步需要额外处理
- 大库笔记数量极多时，软件加载速度会有所下降

### 2.Typora

Typora 是一款极简风格的 Markdown 编辑器，主打**所见即所得**的实时预览，编辑时直接渲染排版效果，无需在源码和预览窗口来回切换，写文档、README、笔记都很方便。

✅ **优点**
- 所见即所得，编辑和预览合一，操作直观，上手简单
- 支持完整 Markdown 语法，支持表格、公式、图片、目录、代码块等
- 一键切换源代码模式（`Ctrl + /`），方便复制原始md源码上传GitHub
- 丰富的主题样式，可自定义字体、配色，导出PDF/Word/图片等多种格式
- 大纲面板快速跳转文档段落，长文档编辑体验优秀
- 跨平台支持 Windows、macOS、Linux

❌ **缺点**
- 商业软件，免费试用有次数限制，长期使用需要购买授权
- 不提供云同步，笔记文件保存在本地，跨设备同步需要自己搭配网盘等方案
- 没有移动端版本，仅支持电脑端
- 部分复杂语法、高级自定义功能不如VS Code等编辑器灵活

> 提示：非常适合编写GitHub的README.md文档，写完切换源码模式，直接复制源码提交到仓库。
>
> 这里提供下载即可用的便携版（见上面文件）

> 提示：下载后先核对压缩包体积与官网一致，解压后按左侧分类逐项使用；新机验机优先跑 CPU-Z、AIDA64、FurMark 和 CrystalDiskInfo，即可快速摸清整机配置与稳定性。

> 提示：建议断网并在 Windows 安全模式下运行，使用前可先创建系统还原点；个别杀毒软件可能误报，请从官网下载并核对校验值。
